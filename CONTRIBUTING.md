# Beiträge / Contributing

## Deutsch

Danke für Dein Interesse an Reisefolio. Hilfreich sind insbesondere präzise Fehlerberichte, verständlichere Anweisungen, bessere Übersetzungen und Erfahrungen aus tatsächlich umgesetzten Reisen.

### Fehler und Ideen

Erstelle ein Issue mit dem betroffenen Abschnitt, dem erwarteten Verhalten und dem tatsächlich beobachteten Ergebnis. Nenne die verwendete Prompt-Sprache, die ChatGPT-Umgebung und den Zeitpunkt des Versuchs. Unterscheide einen Fehler im Prompt von einer in Deinem Konto fehlenden Funktion.

Nutze anonymisierte Beispiele. Keine PINs, API-Schlüssel, Buchungsnummern, privaten Adressen oder ungefragt veröffentlichten Reisebilder.

### Änderungen per Pull Request

1. Beschreibe zunächst das konkrete Problem und die gewünschte Wirkung.
2. Ändere die deutsche und englische Promptfassung gemeinsam. Falls Du nur eine Sprache bearbeiten kannst, kennzeichne die ausstehende Übersetzung.
3. Bewahre die gleiche Abschnittsnummerierung und die Bedeutung der verbindlichen Regeln.
4. Halte die Dokumentation auf Deutsch zuerst und Englisch danach. Die beiden Promptdateien bleiben jeweils einsprachig.
5. Beschreibe, was Du tatsächlich geprüft hast. Ein Textvergleich ist kein vollständiger Umsetzungstest.
6. Führe Änderungen im CHANGELOG auf und erhalte vorhandene Quellen- und Urheberhinweise.

Mit dem Einreichen eigener Beiträge zur Übernahme in dieses Projekt stellst Du diese unter CC BY-NC-SA 4.0 bereit. Reiche nur Inhalte ein, für die Du die erforderlichen Rechte hast. Bewahre bestehende Namensnennungen und kennzeichne Bearbeitungen. Der vollständige Lizenztext steht in [LICENSE](LICENSE).

## English

Thank you for your interest in Reisefolio. Precise bug reports, clearer instructions, better translations and experience from actually implemented trips are particularly helpful.

### Bugs and ideas

Open an Issue with the affected section, expected behaviour and actual result. Include the prompt language, ChatGPT environment and date of your attempt. Distinguish a prompt defect from a capability unavailable in your account.

Use anonymised examples. Do not include PINs, API keys, booking references, private addresses or travel photos published without permission.

### Pull requests

1. Describe the concrete problem and intended effect.
2. Update the German and English prompts together. If you can only edit one language, identify the pending translation.
3. Preserve matching section numbers and the meaning of mandatory rules.
4. Keep documentation German first and English below. Each prompt file remains monolingual.
5. Describe what you actually verified. A textual comparison is not a full implementation test.
6. Record changes in the CHANGELOG and retain existing source and attribution notices.

By submitting your own contributions for inclusion in this project, you make them available under CC BY-NC-SA 4.0. Only submit content for which you hold the necessary rights. Preserve existing attribution and indicate modifications. See [LICENSE](LICENSE) for the full legal text.
